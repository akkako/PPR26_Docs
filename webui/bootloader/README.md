# PPR26 Bootloader 升级工具（网页版）

通过 WebUSB 在浏览器中为 PPR26 升级固件，无需安装本地程序，支持 Chrome / Edge 109+。

- 在线地址：<https://akkako.github.io/PPR26_Docs/bootloader/>
- 本目录的 `index.html` 为同功能版本，可用本地 HTTP 服务打开调试（见 [本地调试](#本地调试)）。

## 使用方式

1. 让设备进入 DFU 模式：断开仪器电源，按住后面板上的 DFU 升级按键，重新接入电源后再松开（也可在通信模式下用 `AT+DEV.DFU` / `SYST:DFU` 命令免按键进入）。
2. 在 Chrome / Edge 中打开在线地址（或通过本地 HTTP 服务打开本目录的 `index.html`，见下）。
3. 点击 **连接设备**，在弹出的设备列表中选择 `PPR26 WinUSB DFU`。
4. 点击 **一键升级**，等待自动完成"擦除 → 烧录 → 校验 → 跳转"。

升级完成后仪器会自动退出 DFU 模式并运行新固件。

## 固件来源

页面**不需要选择固件文件**：打开时自动读取站点上的 `firmware/VERSION`（第一行版本号、
第二行固件文件名），并把同目录下的对应镜像加载进内存，升级框显示版本号与文件名。
连接设备后，设备信息中的**固件版本**会标注 `（已是最新）` 或 `（可升级到 FW x.y.z）`。

在 `firmware/` 下更新固件时，只需替换镜像并把 `VERSION` 的两行改成新的版本号与文件名。

## 固件文件要求

- `firmware/VERSION` 指定的 `*_pack.bin` 镜像（随本仓库发布，与升级页面同源）。
- 不要使用 `.hex` 或其它未经打包的文件，也不要手工改名冒充 `*_pack.bin`。

## 本地调试

本目录的 `index.html` 需通过 HTTP 服务打开（WebUSB 不支持 `file://`）；
固件取自仓库根的 `firmware/`，因此请以**仓库根目录**为站点根启动服务：

```bash
python -m http.server 8000     # 在仓库根目录执行
# 浏览器打开 http://localhost:8000/webui/bootloader/
```

## 设备信息

连接成功后，页面会显示设备信息：

| 信息条目 | 说明 |
| -------- | ---- |
| 供应商 | 设备厂商标识 |
| 设备型号 | `PPR26` |
| 设备序列号 | 芯片唯一序列号 |
| 制造日期 | 格式 `YY-WW`，例如 `26-09` 表示 2026 年第 09 周 |
| 硬件版本 | 单个数字 `0`-`6` |
| Bootloader 版本 / 编译时间 | 引导程序信息 |
| 固件版本 / 编译时间 | 当前应用固件信息 |
| 页缓冲区大小 | 升级分块大小 |

## 常见问题

### 设备列表里找不到设备

- 确认设备已进入 DFU 模式（步骤 1）。
- 本工具只支持 WinUSB Bootloader 设备。
- 关闭可能占用设备的程序，例如其它浏览器标签页或串口工具。
- 若曾在同一设备上安装过旧驱动，可在系统"设备管理器"中卸载该设备并重新插拔，让系统重新识别。
