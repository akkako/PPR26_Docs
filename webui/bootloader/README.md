# PPR26 Bootloader 升级工具（网页版）

通过 WebUSB 在浏览器中为 PPR26 升级固件，无需安装本地程序，支持 Chrome / Edge 109+。

- 在线地址：<https://akkako.github.io/PPR26_Docs/bootloader/>
- 本目录的 `index.html` 为同功能的离线版本，可用本地 HTTP 服务打开调试。

## 使用方式

1. 让设备进入 DFU 模式：断开仪器电源，按住前面板上的 DFU 升级按键，重新接入电源后再松开。
2. 在 Chrome / Edge 中打开在线地址（或本目录的 `index.html`）。
3. 点击 **连接设备**，在弹出的设备列表中选择 `PPR26 WinUSB DFU`。
4. 点击 **选择固件**，选择随版本发布的固件镜像文件（`*_pack.bin`）。
5. 点击 **一键升级**，等待自动完成"擦除 → 烧录 → 校验 → 跳转"。

升级完成后仪器会自动退出 DFU 模式并运行新固件。

## 固件文件要求

- 请选择随版本发布的 `*_pack.bin` 固件镜像。
- **不要**选择 `.hex` 或其它未经打包的文件。

## 设备信息

连接成功后，页面会显示设备信息：

| 信息条目 | 说明 |
| -------- | ---- |
| 供应商 | 设备厂商标识 |
| 设备型号 | `PPR26` |
| 设备序列号 | 芯片唯一序列号 |
| 制造日期 | 格式 `YY-WW`，例如 `26-09` 表示 2026 年第 09 周 |
| 硬件版本 | 单个数字 `0`-`6` |
| Bootloader 版本 / 编译时间 | 引导程序信息 |
| 固件版本 / 编译时间 | 当前应用固件信息 |
| 页缓冲区大小 | 升级分块大小 |

## 常见问题

### 设备列表里找不到设备

- 确认设备已进入 DFU 模式（步骤 1）。
- 本工具只支持新版 WinUSB Bootloader 设备；旧版 HID 设备不被支持。
- 关闭可能占用设备的程序，例如其它浏览器标签页或串口工具。
- 若曾在同一设备上安装过旧驱动，可在系统"设备管理器"中卸载该设备并重新插拔，让系统重新识别。
