# PPR26 程控电阻

PPR26 是一款精密程控电阻箱，支持 **USB-CDC（AT 命令）** 与 **USB-TMC（SCPI 命令）** 两种控制方式。可通过上位机设置输出阻值、限值与输出状态，并支持用户校准。
