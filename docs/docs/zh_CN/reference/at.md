# AT 命令参考

## 设备连接参数配置

PPR26 在 USB-CDC 模式下免驱，可使用 AT 指令进行编程。PC 端串口参数配置为：

| 波特率 | 数据位 | 校验位 | 停止位 |
| ------ | ------ | ------ | ------ |
| 115200 | 8      | None   | 1      |

用户可以通过串口上位机在 PC 端控制设备输出、执行用户校准以及查看设备信息。

本文示例采用如下记法（`>` 为发送内容，`<` 为设备返回内容，不随命令发送）：

```text
> AT+DEV.MODEL?
< +DEV.MODEL=PPR26
```

## 通用规则

### 命令类型

| 类型     | 命令格式            | 说明                   |
| -------- | ------------------- | ---------------------- |
| 测试命令 | `AT+<命令名称>=?`   | 查询参数帮助及取值范围 |
| 查询命令 | `AT+<命令名称>?`    | 返回当前参数值         |
| 设置命令 | `AT+<命令名称>=<…>` | 设置参数并执行         |
| 执行命令 | `AT+<命令名称>`     | 执行无参数命令         |

- 并非每条命令都具备上述四种类型；请以各命令的“命令形式”为准。
- 命令**区分大小写**，命令名须使用大写（例如 `AT+RES.SP`）。
- 参数以 `,` 分隔，最多 8 个，每个最长 64 字节；数值参数支持十进制与 `0x` 十六进制（无符号，`AT+CALI.VAL` 例外，按有符号解析）。
- 单条命令长度不超过 256 字节，超出时返回 `OVERFLOW`。
- 命令以 `<CR>`、`<LF>` 或 `<CR><LF>` 结束。
- 测试形式 `=?` 仅对声明了该形式的命令有效；仅有查询形式的命令（`AT+DEV.*`、`AT+RES.PV`、`AT+CALI.COUNT`、`AT+CALI.TEMP`）使用 `=?` 会返回 `ERROR`。

### 通用响应

| 响应                 | 说明                                              |
| -------------------- | ------------------------------------------------- |
| `+<命令>=<值>`       | 查询结果                                          |
| `OK`                 | 设置/执行成功                                     |
| `ERROR`              | 参数错误、越界、不支持的调用类型或未知命令        |
| `OVERFLOW`           | 单条命令超过 256 字节                             |
| `[TQS ] AT+<命令>=…` | `=?` 参数帮助（`T`=Test、`Q`=Query、`S`=Set）      |

- 每条应答以 `<CR><LF>` 结束，不含额外字节。
- 未知命令、大小写不符或形式非法的命令均返回 `ERROR`；空行不产生应答。

### 单位与约定

- 阻值相关参数与返回值统一为**毫欧（mΩ）整数**，内部为 64 位整数，以十进制输出。
- 阻值有效范围：**5 Ω ~ 4 MΩ**（`5000` ~ `4000000000` mΩ）。
- 温度统一为 **0.1 ℃** 整数（例如 `291` 表示 29.1 ℃）。
- 超量程只返回 `ERROR`，不改变当前值，也不会自动切到短路或开路。
- 每次上电输出为**开路**，此时 `AT+RES.PV?` 返回 `inf`。

### 保存策略

- **会保存**（设置后立即写入非易失存储，断电后保持）：通信协议、步进值、限值（`MIN` / `MAX`）与限值使能、补偿模式、数据集选择、上电统计。
- **不保存**（仅本次通电会话有效）：设定阻值 `AT+RES.SP`、输出状态 `AT+RES.SHORT` / `AT+RES.OPEN`、继电器位图 `AT+RES.NETW`，以及校准使能 `AT+CALI.ENAB` 与校准档位 `AT+CALI.GEAR`。重新上电后设备为**开路 + 默认设定值 5 Ω**。
- **校准数据**只在校准写入操作时保存：`AT+CALI.SAVE`、`AT+CALI.LOCK=1`、设置用户密码；选择数据集不会写入校准数据。
- 配置项出厂默认：补偿模式 `2`（多档位最佳）、步进 `1000` mΩ（1 Ω）、限值使能 `0`、限值范围即满量程（5 Ω ~ 4 MΩ）；数据集默认为 `USER`。

## 设备信息命令

### `AT` — 连接测试

- **命令形式**：`AT`（执行）
- **参数**：无
- **返回**：`OK`
- **说明**：用于检测设备在线与串口联通。

**示例**

```text
> AT
< OK
```

### `AT+DEV.SN?` — 序列号

- **命令形式**：`AT+DEV.SN?`（查询）
- **参数**：无
- **返回**：`+DEV.SN=<序列号>`，24 个大写十六进制字符。
- **说明**：序列号是设备的唯一标识，与 USB 描述符中的序列号以及 SCPI 侧 `SYST:INFO:SN?` 返回的序列号一致。

**示例**

```text
> AT+DEV.SN?
< +DEV.SN=0123456789ABCDEF01234567
```

### `AT+DEV.MODEL?` — 型号

- **命令形式**：`AT+DEV.MODEL?`（查询）
- **参数**：无
- **返回**：`+DEV.MODEL=PPR26`

**示例**

```text
> AT+DEV.MODEL?
< +DEV.MODEL=PPR26
```

### `AT+DEV.PROD?` — 生产日期

- **命令形式**：`AT+DEV.PROD?`（查询）
- **参数**：无
- **返回**：`+DEV.PROD=<YY-WW>`，年（两位）与周（两位）。

**示例**

```text
> AT+DEV.PROD?
< +DEV.PROD=26-09
```

### `AT+DEV.HWVER?` — 硬件版本

- **命令形式**：`AT+DEV.HWVER?`（查询）
- **参数**：无
- **返回**：`+DEV.HWVER=<0..6>`

**示例**

```text
> AT+DEV.HWVER?
< +DEV.HWVER=0
```

### `AT+DEV.FWVER?` — 固件版本

- **命令形式**：`AT+DEV.FWVER?`（查询）
- **参数**：无
- **返回**：`+DEV.FWVER=<版本字符串>`

**示例**

```text
> AT+DEV.FWVER?
< +DEV.FWVER=FW 1.0.0
```

### `AT+DEV.POWERON?` — 上电次数

- **命令形式**：`AT+DEV.POWERON?`（查询）
- **参数**：无
- **返回**：`+DEV.POWERON=<次数>`

**示例**

```text
> AT+DEV.POWERON?
< +DEV.POWERON=12
```

### `AT+DEV.UPTIME?` — 累计通电时间

- **命令形式**：`AT+DEV.UPTIME?`（查询）
- **参数**：无
- **返回**：`+DEV.UPTIME=<分钟>`，单位分钟，永不清零。

**示例**

```text
> AT+DEV.UPTIME?
< +DEV.UPTIME=345
```

### `AT+DEV.DFU` — 进入固件升级模式

- **命令形式**：`AT+DEV.DFU`（执行）
- **参数**：无
- **返回**：`OK`
- **说明**：无需按键即可让设备进入 **DFU（固件升级）模式**：设备返回 `OK` 后自动断开 USB 并重启，随后以 `PPR26 WinUSB DFU`（`0xFFFE:0xFFFD`）重新枚举，等待上位机升级。
- **注意**：设备随即断开，`OK` 应答可能来不及送达上位机，**以设备是否重新枚举为 DFU 设备作为成功判据**；升级完成或重新上电后回到正常运行。升级步骤见[固件升级指南](../quickstart/fwupgrade.md)。

**示例**

```text
> AT+DEV.DFU
< OK
```

## 温度测量命令

设备板载 NTC 温度传感器，用于监测设备内部温度。温度单位为 **0.1 ℃**。

### `AT+DEV.TEMP?` — 当前温度

- **命令形式**：`AT+DEV.TEMP?`（查询）
- **参数**：无
- **返回**：`+DEV.TEMP=<温度×10>`，例如 `291` 表示 29.1 ℃。

**示例**

```text
> AT+DEV.TEMP?
< +DEV.TEMP=291
```

### `AT+DEV.TSTAT?` — 温度统计

- **命令形式**：`AT+DEV.TSTAT?`（查询）
- **参数**：无
- **返回**：`+DEV.TSTAT=<当前>,<最低>,<平均>,<最高>,<采样次数>`
  （前四项为 0.1 ℃ 整数，末项为整数）
- **说明**：统计自开机或上次 `AT+DEV.TCLR` 起累计。

**示例**

```text
> AT+DEV.TSTAT?
< +DEV.TSTAT=291,290,291,293,1250
```

### `AT+DEV.TCLR` — 清空温度统计

- **命令形式**：`AT+DEV.TCLR`（执行）
- **参数**：无
- **返回**：`OK`
- **说明**：清空最高/最低/平均/采样次数，重新开始统计。

**示例**

```text
> AT+DEV.TCLR
< OK
```

## 系统命令

### `AT+SYS.PROT` — 通信协议

- **命令形式**：`AT+SYS.PROT?`（查询） / `AT+SYS.PROT=<0|1>`（设置） / `AT+SYS.PROT=?`（测试）
- **参数**：`0` = AT（USB CDC），`1` = SCPI（USB TMC）
- **返回**：查询返回 `+SYS.PROT=<0|1>`
- **说明**：设置后**保存并运行时切换**：设备断开/重连 USB 后按新协议重新枚举，**不复位 MCU**。切换期间当前连接会中断。

**示例**

```text
> AT+SYS.PROT?
< +SYS.PROT=0

> AT+SYS.PROT=1
< OK
```

## 输出与电阻命令

阻值单位统一为 mΩ。以下命令的 `=?` 形式返回参数帮助（部分命令还会打印取值范围）。

### `AT+RES.SP` — 设定阻值

- **命令形式**：`AT+RES.SP?`（查询） / `AT+RES.SP=<mΩ>`（设置） / `AT+RES.SP=?`（测试）
- **参数**：`<mΩ>` 阻值，范围 **5000 ~ 4000000000**（5 Ω ~ 4 MΩ）
- **返回**：查询返回 `+RES.SP=<mΩ>`
- **说明**：
  - 限值使能（`AT+RES.LIMIT=1`）时，设定值须落在 `[RES.MIN, RES.MAX]` 内。
  - 设置成功后输出状态变为电阻网络输出（NORM）。
  - 越界返回 `ERROR` 且保持原值。
  - 设定值**只在本次通电会话内有效**：设备不把它写入非易失存储，重新上电后回到默认值 5 Ω；需要时请在开机后重新设置。

**示例**

```text
> AT+RES.SP=523000
< OK

> AT+RES.SP?
< +RES.SP=523000
```

### `AT+RES.PV?` — 当前估测阻值

- **命令形式**：`AT+RES.PV?`（查询）
- **参数**：无
- **返回**：`+RES.PV=<mΩ>`；开路时返回 `+RES.PV=inf`；短路时返回当前数据集（`AT+CALI.SEL`）的短路校准值。
- **说明**：返回值按**实际输出状态**计算（与 SCPI 侧共用同一输出状态）：开路输出返回 `inf`，短路输出返回短路校准值，电阻网络输出返回按当前数据集补偿估测的阻值。每次上电初始输出为开路，因此开机后首次查询通常为 `inf`。

**示例**

```text
> AT+RES.PV?
< +RES.PV=523000
```

### `AT+RES.COMP` — 补偿模式

- **命令形式**：`AT+RES.COMP?`（查询） / `AT+RES.COMP=<模式>`（设置） / `AT+RES.COMP=?`（测试）
- **参数**：`0` = 不补偿（UNCAL）、`1` = 附近最佳（NEARBY）、`2` = 多档位最佳（PREC，默认）
- **返回**：查询返回 `+RES.COMP=<0|1|2>`
- **说明**：补偿模式会被保存，断电后保持；修改后**下次 `AT+RES.SP` 时生效**。`1` / `2` 依赖当前数据集的校准数据：校准值为 0 时 `1` 退化为标称映射、`2` 输出近似 0 档，`0` 不受影响。

**示例**

```text
> AT+RES.COMP=2
< OK

> AT+RES.COMP?
< +RES.COMP=2
```

### `AT+RES.STEP` — 步进值

- **命令形式**：`AT+RES.STEP?`（查询） / `AT+RES.STEP=<mΩ>`（设置） / `AT+RES.STEP=?`（测试）
- **参数**：`<mΩ>` 步进值，任意非负整数（无上限）；负值返回 `ERROR`（原值不变）
- **返回**：查询返回 `+RES.STEP=<mΩ>`
- **说明**：步进值会被保存，断电后保持。

**示例**

```text
> AT+RES.STEP=10000
< OK

> AT+RES.STEP?
< +RES.STEP=10000
```

### `AT+RES.LIMIT` — 限值使能

- **命令形式**：`AT+RES.LIMIT?`（查询） / `AT+RES.LIMIT=<0|1>`（设置） / `AT+RES.LIMIT=?`（测试）
- **参数**：`0` = 关闭、`1` = 使能
- **返回**：查询返回 `+RES.LIMIT=<0|1>`
- **说明**：使能后，设定阻值必须落在 `[RES.MIN, RES.MAX]` 内；使能状态会被保存，断电后保持。

**示例**

```text
> AT+RES.LIMIT=1
< OK

> AT+RES.LIMIT?
< +RES.LIMIT=1
```

### `AT+RES.NETW` — 继电器网络

- **命令形式**：`AT+RES.NETW?`（查询） / `AT+RES.NETW=<mask>`（设置） / `AT+RES.NETW=?`（测试）
- **参数**：`<mask>` 26 位继电器位图，范围 `0` ~ `67108863`（`2^26 - 1`）
- **返回**：查询返回 `+RES.NETW=<mask>`
- **说明**：直接应用 26 位继电器位图（绕过补偿算法），并把设定阻值改写为该位图对应的仿真阻值、输出状态置为**电阻网络输出**（`NORM`），用于产测与校准。执行后的设定值与输出状态**只在本次会话有效**（不写非易失存储）；**位图本身也不保存**，重新上电后设备为开路 + 默认设定值 5 Ω。

**示例**

```text
> AT+RES.NETW=0
< OK
```

### `AT+RES.MAX` — 最大阻值限制

- **命令形式**：`AT+RES.MAX?`（查询） / `AT+RES.MAX=<mΩ>`（设置） / `AT+RES.MAX=?`（测试）
- **参数**：`<mΩ>`，范围 5 Ω ~ 4 MΩ
- **返回**：查询返回 `+RES.MAX=<mΩ>`
- **说明**：须满足 `RES.MIN ≤ RES.MAX`，否则返回 `ERROR`；设置会被保存，断电后保持。设置限值**不会**自动使能限值判定（需 `AT+RES.LIMIT=1`）。

**示例**

```text
> AT+RES.MAX=1000000
< OK
```

### `AT+RES.MIN` — 最小阻值限制

- **命令形式**：`AT+RES.MIN?`（查询） / `AT+RES.MIN=<mΩ>`（设置） / `AT+RES.MIN=?`（测试）
- **参数**：`<mΩ>`，范围 5 Ω ~ 4 MΩ
- **返回**：查询返回 `+RES.MIN=<mΩ>`
- **说明**：须满足 `RES.MIN ≤ RES.MAX`，否则返回 `ERROR`；设置会被保存，断电后保持。设置限值**不会**自动使能限值判定（需 `AT+RES.LIMIT=1`）。

**示例**

```text
> AT+RES.MIN=5000
< OK
```

### `AT+RES.SHORT` / `AT+RES.OPEN` — 短路 / 开路

- **命令形式**：`AT+RES.SHORT?`/`AT+RES.OPEN?`（查询） / `AT+RES.SHORT=<0|1>`/`AT+RES.OPEN=<0|1>`（设置） / `=?`（测试）
- **参数**：`1` = 进入短路/开路，`0` = 恢复到当前设定阻值（`AT+RES.SP`）
- **返回**：查询返回 `<0|1>`
- **说明**：短路/开路状态与 SCPI 侧（`OUTPut`）**共用**；除本命令外，`AT+RES.SP`、`AT+RES.NETW` 也会把输出切回电阻网络输出，`AT+CALI.GEAR=26` / `27` 会直接驱动短路通路。输出状态**不跨上电保持**——每次上电的初始输出恒为**开路**，需重新设置阻值或发送 `AT+RES.OPEN=0` / `AT+RES.SHORT=0` 才回到电阻网络输出。

**示例**

```text
> AT+RES.OPEN=1
< OK

> AT+RES.PV?
< +RES.PV=inf
```

## 校准命令

设备保存两套校准数据，`AT+CALI.SEL` 决定当前生效（用于输出）以及后续编辑的目标数据集：

| 数据集 | 说明 |
| ------ | ---- |
| `USER`（`0`） | **用户校准**，默认数据集，用户可自行校准与修改 |
| `FACTORY`（`1`） | **出厂校准**，出厂时写入，不提供用户修改方法 |

!!! note "出厂数据不会被用户校准影响"
    出厂校准数据集默认处于**锁定**状态，解锁所需的出厂口令不对外提供；因此按本文流程操作用户数据集，**不会修改或覆盖出厂校准数据**。如需重新校准，请对 `USER` 数据集操作。

!!! warning "注意"
    校准不当会降低输出精度与可靠性，请在具备参考标准的情况下进行。

### 校准流程与写保护

写入校准数据（`VAL` / `DATE` / `STR` / `SAVE`）前必须满足：

1. 已进入校准模式：`AT+CALI.ENAB=1`；
2. 目标数据集未锁定（用户数据集已设置密码时需先 `AT+CALI.UNL` 解锁）。

查询命令不受上述限制；违反写保护时返回 `ERROR`。**例外**是修改或清除用户密码（`AT+CALI.PASS`），它只要求数据集未锁定，与 `ENAB` 无关。

> AT 与 SCPI 共用同一份校准数据与同一套锁定/解锁判定：在任一侧校准，切到另一侧即可读取。

### `AT+CALI.SEL` — 校准数据集

- **命令形式**：`AT+CALI.SEL?`（查询） / `AT+CALI.SEL=<0|1>`（设置） / `AT+CALI.SEL=?`（测试）
- **参数**：`0` = `USER`（用户校准）、`1` = `FACTORY`（出厂校准）
- **返回**：查询返回 `+CALI.SEL=<0|1>`
- **说明**：所选数据集同时决定设备按哪套数据输出阻值，以及后续 `AT+CALI.*` 命令的编辑目标；选择结果会**立即保存**在设备配置项中（与校准数据分开存放）、断电后保持，且**不会改动校准数据本身**（切换数据集不写入任何校准值）。

**示例**

```text
> AT+CALI.SEL=0
< OK

> AT+CALI.SEL?
< +CALI.SEL=0
```

### `AT+CALI.ENAB` — 校准使能

- **命令形式**：`AT+CALI.ENAB?`（查询） / `AT+CALI.ENAB=<0|1>`（设置） / `AT+CALI.ENAB=?`（测试）
- **参数**：`0` = 退出校准模式、`1` = 进入校准模式
- **返回**：查询返回 `+CALI.ENAB=<0|1>`
- **说明**：写入校准数据的前置条件，**不持久化**（掉电后为 `0`）。

**示例**

```text
> AT+CALI.ENAB=1
< OK
```

### `AT+CALI.PASS` — 用户密码

- **命令形式**：`AT+CALI.PASS?`（查询） / `AT+CALI.PASS=<string>`（设置） / `AT+CALI.PASS=?`（测试）
- **参数**：`<string>` 密码，最长 64 字节；空字符串表示清除密码（清除后默认解锁）
- **返回**：查询返回 `+CALI.PASS=<0|1>`（是否已设密码，不返回明文）
- **说明**：仅对 `USER` 数据集有效——选中 `FACTORY`（`AT+CALI.SEL=1`）时查询与设置都返回 `ERROR`；设置非空密码会同时把数据集置为**锁定**，空字符串则清除密码并解锁。**修改或清除密码要求数据集当前未锁定**（解锁用 `AT+CALI.UNL`），否则返回 `ERROR`。

**示例**

```text
> AT+CALI.PASS=1234
< OK

> AT+CALI.PASS?
< +CALI.PASS=1
```

### `AT+CALI.UNL` — 解锁

- **命令形式**：`AT+CALI.UNL=<password>`（设置） / `AT+CALI.UNL=?`（测试）
- **参数**：`<password>` 用户密码；`USER` 数据集密码为空时可直接解锁（`AT+CALI.UNL=`）
- **返回**：`OK` / `ERROR`（密码错误时返回 `ERROR`）
- **说明**：作用于 `AT+CALI.SEL` 选中的数据集；`FACTORY` 数据集不提供用户可用的解锁方式。解锁状态**只在本次通电会话内有效**（`UNL` 本身不写入存储）：若要让解锁状态在断电后保持，请在解锁后执行一次会写入校准数据的操作（例如校准后 `AT+CALI.SAVE`）；否则重新上电后数据集仍是上次保存的锁定状态。

**示例**

```text
> AT+CALI.UNL=1234
< OK
```

### `AT+CALI.LOCK` — 锁定

- **命令形式**：`AT+CALI.LOCK?`（查询） / `AT+CALI.LOCK=<0|1>`（设置） / `AT+CALI.LOCK=?`（测试）
- **参数**：`1` = 锁定；`0` 仅在**未锁定**时为空操作
- **返回**：查询返回 `+CALI.LOCK=<0|1>`
- **说明**：**解锁只能通过 `AT+CALI.UNL` + 密码**；已锁定时执行 `AT+CALI.LOCK=0` 返回 `ERROR`。`AT+CALI.LOCK=1` 会立即把锁定状态写入校准数据，断电后保持。

**示例**

```text
> AT+CALI.LOCK=1
< OK

> AT+CALI.LOCK?
< +CALI.LOCK=1
```

### `AT+CALI.GEAR` — 校准档位

- **命令形式**：`AT+CALI.GEAR?`（查询） / `AT+CALI.GEAR=<0..27>`（设置） / `AT+CALI.GEAR=?`（测试）
- **参数**：`<0..27>`，含义见下表；设置时同时应用对应继电器
- **返回**：查询返回 `+CALI.GEAR=<0..27>`
- **说明**：档位为会话状态，不持久化。

| 档位      | 含义                       |
| --------- | -------------------------- |
| `0`..`25` | 单路电阻（闭合对应继电器） |
| `26`      | 串联短路                   |
| `27`      | 直接短路                   |

**示例**

```text
> AT+CALI.GEAR=0
< OK
```

- **返回**：查询返回 `+CALI.VAL=<mΩ>`
- **说明**：受写保护约束（需 `ENAB=1` 且未锁定）。
