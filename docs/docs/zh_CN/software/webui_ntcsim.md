# NTC 模拟器（网页版）

网页版 NTC 模拟器把 PPR26 当作**热敏电阻**使用：按你选择的 NTC 模型把温度换算成阻值并下发到设备，
也可以由阻值反解温度、按温度步进、查看温度-阻值曲线。**无需安装任何软件**，
不连接设备时也能进行全部换算与查看。

网址：<https://akkako.github.io/PPR26_Docs/ntcsim/>

!!! note "使用条件"
    - 浏览器：**Chrome / Edge 109 及以上**；只做换算与看曲线时任意现代浏览器均可。
    - 需要把阻值下发到设备时，设备须工作在 **AT 模式**，切换方法见[通信模式切换](../quickstart/modeswitch.md)。
    - 设备可输出的阻值范围是 **5 Ω ~ 4 MΩ**；模型给出的阻值超出该范围时不会被下发（原因记录在 AT 日志里）。

## 使用前准备

1. 想好要模拟的 NTC 参数：数据手册的 R25 与 B 值、若干组标定数据，或一份 CSV 数据文件。
2. 需要下发阻值时：让设备工作在 AT 模式，并关闭其它可能占用该串口的程序。
3. 用 Chrome 或 Edge 打开 <https://akkako.github.io/PPR26_Docs/ntcsim/>。

页面右上角的两个按钮分别用于**切换亮/暗主题**与**中英文界面**，设置会保存在浏览器本地，
与其它网页工具共用。点击页头的 **←** 可返回[工具中心](https://akkako.github.io/PPR26_Docs/)。

## 连接设备

1. 点击 **连接设备**。
2. 在弹出的设备列表中选择 PPR26。
3. 连接成功后状态显示 **已连接**，顶部同一行会显示设备信息与内部温度。

!!! tip "看不到设备？"
    - 确认设备工作在 **AT 模式**：其它模式下的设备不会出现在串口列表中。
    - 确认设备已通过 USB 连接，且其它程序（串口工具、Python 脚本、另一个浏览器标签页）没有占用它。
    - 请使用 `https://` 或本机的 `http://localhost` 打开页面，其它地址下浏览器会禁用串口访问。

设备**不会记住上次的设定值**：重新上电或重新连接后，输出是断开的、设定值回到默认值。
勾选了 **自动设置** 时，页面在连接成功后会立即把当前模拟点重新下发一次。

## 固件版本检查

连接后，如果设备固件比当前发布版本旧，页面会弹出**无法关闭**的提示，并让设备自动进入升级模式。
按下面的步骤操作即可：

1. 出现提示后设备会断开并重启为升级设备——页面回到"未连接"、串口从列表里消失，都是正常现象；
2. 点击提示框里的 **前往升级**，按升级工具的指引完成升级；
3. 升级完成后重新连接设备，提示会自动消失；已升级但提示还在时，点 **重新检测** 立即复核。

固件与发布版本一致、或设备版本更新（例如开发版本）时**不会出现任何提示**，可以正常使用。
完整说明见[串口上位机（网页版）](webui_serial.md)。

## 界面说明

页面分为三栏（窄屏自动堆叠为两栏/单栏）：

| 区域 | 内容 |
| ---- | ---- |
| **顶部（连接行）** | 连接 / 断开按钮、连接状态，以及同一行的设备信息：型号 / 序列号 / 固件 / 硬件版本、**设备内部温度**、输出状态（宽度不足时自动换行） |
| **左栏 · NTC 模型** | 三种建模方式（三选一；B 值法与 SH 方程各自还有"直填参数 / 标定点拟合"两种子方式）、参数与标定点表、CSV 导入；底部是当前模型的精简摘要 |
| **左栏 · 设备限值窗口** | 启用限值、最小/最大阻值、写入限制值；用法见下文「设备限值窗口」一节 |
| **中栏 · 温度控制台** | 当前模拟温度（大字）、其下方的四个读数（目标 / SP / PV / TP）、温度输入与计算/应用、自动设置、温度步进、阻值反解 |
| **右栏 · 曲线** | 温度-阻值曲线、当前模拟点与设备实际值的标记、允许窗口阴影、悬停与点击交互 |
| **底部 · AT 日志** | 默认折叠。页面上不显示任何提示文字，需要知道"为什么没做成"时展开这里 |

## 选择 NTC 模型（三选一）

同一时刻只使用一种建模方式，切换方式时右侧曲线与换算结果同步更新。

### B 值法

适合只有数据手册参数的场景，提供三种输入方式（子选项卡，只显示所选一种）：

| 子方式 | 填什么 | 说明 |
| ---- | ---- | ---- |
| **直填 R25/B** | R25（25 ℃ 阻值）与 B（如 3435 K） | 数据手册上的两个标准参数 |
| **两点反算** | 两组 (温度, 阻值) | 由这两个点确定模型 |
| **多点拟合** | 2 个以上标定点 | 点数越多越稳，推荐 5 个以上；面板会显示各点残差 |

### Steinhart-Hart

| 子方式 | 填什么 | 说明 |
| ---- | ---- | ---- |
| **直填 A/B/C** | 三个系数 | 使用厂商给出的系数，或你在其它地方拟合好的系数（`3.2e-8` 这类写法可以直接粘贴） |
| **标定点拟合** | 3 个以上标定点 | 点数越多越稳，推荐 5 个以上；面板会显示各点残差 |

系数对应 `1/T = A + B·ln R + C·(ln R)³`（T 为开尔文温度，R 为欧姆），三个输入框的悬停提示里有典型值。
**残差**表示模型与标定数据的偏差：在 mK 量级说明模型很贴合，明显偏大通常是标定点填错了
（温度与阻值不对应，或出现重复温度）。摘要里出现**不单调**警告时说明系数有问题，请检查输入。

### 导入 CSV

选择或拖入一个数据文件，然后二选一：

| 子方式 | 说明 |
| ---- | ---- |
| **原始数据插值**（默认） | 直接按你的数据点换算，不引入任何拟合误差；**数据温度范围之外无法换算** |
| **转换为 SH 拟合** | 用同一批数据得到一组系数，之后可以覆盖更宽的温度范围 |

CSV 格式要求很宽松：

- 每行两列：`温度(℃), 电阻(Ω)`；
- 分隔符支持逗号、分号、制表符；
- 以 `#` 开头的行会被忽略；表头等非数字行会自动跳过；
- 至少 2 个数据点（转换为 SH 拟合需要 3 个以上）。

示例：

```csv
# 10k NTC 标定数据
t_c,r_ohm
0,28443.5
25,10000
50,4112.3
85,1451.3
100,984.5
```

### 当前模型摘要

左栏底部始终显示当前模型的摘要：关键参数、温度范围两端的阻值、拟合残差（如有）与异常警告。
数字按 4 位有效数字显示，便于一眼看清量级；完整数值在输入框与读数里。

## 温度与阻值操作

### 操作语义（先看这张表）

| 操作 | 更新模拟点 | 是否下发到设备 |
| ---- | ---- | ---- |
| 输入温度后点 **计算**（或在温度框中按回车） | 是 | **自动设置勾选时**下发 |
| **− 步进** / **＋ 步进**（步长可填） | 是 | **自动设置勾选时**下发 |
| 点击曲线 | 是 | 否（只更新，不会下发） |
| 阻值 **填入温度** | 是 | 否（只更新，不会下发） |
| **应用** | 不改变模拟点 | **总是下发**当前目标阻值 |

**自动设置**（默认勾选）决定"计算 / 步进"是否顺手下发；取消勾选后所有下发都要手动点 **应用**。
这个开关会记忆在浏览器本地。

!!! tip "大字温度的颜色就是下发状态"
    **绿色 = 仅本地计算**（还没下发，设备端子上的阻值没有变化）；**红色 = 已下发**（设备已按该
    温度输出阻值）。曲线点击、阻值反解只在本地更新模拟点，因此保持绿色；点「计算 / 步进 / 应用」
    真正下发后转为红色。一眼就能分清"算过了"和"发出去了"。

!!! note "页面上没有任何提示文字"
    所有消息——包括"为什么没做成"（输入无效、超出量程、超出限值窗口、设备拒绝、未连接等）
    ——都只写进底部**默认折叠的 AT 日志**。平时界面保持干净，需要排查时展开日志查看即可。

### 一键设置温度对应的阻值

1. 在温度框输入温度（如 `85`），点 **计算**（或按回车）。
2. 模拟温度下方的一排小字给出四个值：**目标**（模型算出的阻值）、**SP**（设备设定的阻值）、
   **PV**（设备实际输出的估测值）、**TP**（PV 折算成的温度）。这一块固定两行，内容变化不会让
   下方按钮上下移动。
3. 勾选 **自动设置** 时第 1 步已经完成下发；否则点 **应用**。

下发前页面会先检查，不满足条件时**不会发送**，原因写进 AT 日志：

- 超出设备可输出的范围（5 Ω ~ 4 MΩ）；
- 超出**设备限值窗口**（启用限值后；见下文「设备限值窗口」一节）；
- 未连接设备。

### 按温度步进

1. 在 **步长** 中填写步长（默认 1.0 ℃，可填 0.1 等更小的值）。
2. 点 **− 步进** / **＋ 步进** 按步长增减温度并（自动设置勾选时）下发。
3. 到达温度范围边界时会**停在边界值**（日志里会记一条），不会发出越界的命令。

### 由阻值反解温度

在 **阻值 → 温度** 输入阻值（可切换 Ω / kΩ / MΩ 单位）：

- 输入过程中即实时显示对应温度；
- 点 **填入温度** 把该温度设为当前模拟点（不会下发，需再点 **计算** 或 **应用**）。

### 目标值与设备实际值

设备的输出阻值只能取到**离散值**，与你请求的值会有小差异，因此页面上同时给出：

- **目标**：模型算出的阻值，也是下发的值；
- **PV** 与 **TP**：设备实际输出的估测值与它折算出的温度。

实测参考（10 kΩ / B25/85 = 3435 K 模型，四线测量，6 次读数平均）：

| 模拟温度 | 请求阻值 | 实测阻值 | 误差 | 折算温度偏差 |
| ---- | ---- | ---- | ---- | ---- |
| 0 ℃ | 28.704290 kΩ | 28.700147 kΩ | −4.14 Ω | +0.003 ℃ |
| 25 ℃ | 10.000000 kΩ | 10.000618 kΩ | +0.62 Ω | −0.002 ℃ |
| 50 ℃ | 4.101190 kΩ | 4.099628 kΩ | −1.56 Ω | +0.012 ℃ |
| 85 ℃ | 1.451347 kΩ | 1.450563 kΩ | −0.78 Ω | +0.020 ℃ |
| 100 ℃ | 987.037 Ω | 986.393 Ω | −0.64 Ω | +0.026 ℃ |
| 125 ℃ | 553.740 Ω | 553.358 Ω | −0.38 Ω | +0.032 ℃ |

这些偏差都在设备自身的精度指标内，折算到温度最大约 0.03 ℃。**阻值越低，同样的绝对偏差
折算到温度上越明显**——这是设备本身的限制，不是计算错误；看 PV / TP 即可知道实际效果。

## 曲线

- **横轴**：温度（默认 −40 ~ 125 ℃，可在曲线右上角修改）；
- **纵轴**：阻值，默认**对数轴**（NTC 阻值跨几个数量级），可取消勾选切换为线性轴；
- **蓝色实线**：当前模型的曲线（CSV 插值模式下只画数据覆盖的温度范围）；
- **实心圆点 ●**：当前模拟点（温度与目标阻值）；
- **空心圆点 ○**：设备实际输出的位置（连接后显示，便于看出偏差）；
- **阴影带 ▓**：设备允许窗口（启用限值后显示，见下节）；
- **悬停**：显示该位置的 (温度, 阻值) 读数；
- **点击**：把该温度设为模拟点（不会下发，需再点 **应用**）。启用限值后，点到窗口外的位置会
  自动落在窗口内最靠近的位置，**保证能下发成功**；
- **高度**：曲线高度随卡片大小自适应。

## 设备限值窗口

把设备的阻值限制窗口搬到本页直接设置（模型卡下方）：

| 控件 | 作用 |
| ---- | ---- |
| **启用限值** | 勾选/取消立即生效。启用后，超出窗口的设定值会被**设备拒绝** |
| **最小阻值 / 最大阻值** | 窗口的上下边界，配单位下拉（Ω / kΩ / MΩ） |
| **写入限制值** | 把两个边界写入设备（最小不能大于最大） |

操作步骤：先填最小/最大 → 点 **写入限制值** → 需要限制生效时再勾选 **启用限值**。

要点：

- **限值保存在设备里，断电后仍然有效**（设定值则不会保存）。不需要限制时请取消勾选，
  必要时把范围改回 5 Ω ~ 4 MΩ。
- 窗口会**直接体现在曲线上**：启用限值后曲线出现阴影带，一眼能看出当前模拟点是否在允许区内。
- 模拟点落在窗口外时，页面会在下发前拦下（不会发出必然被拒的命令），原因记录在 AT 日志。
- 未连接设备时这些控件不可用——限值是设备里的设置，无法离线修改。

## AT 日志

底部 **AT 日志** 默认折叠，展开后显示与设备之间的全部往来记录，以及所有"为什么没做成"的说明
（输入无效、超出量程、超出限值窗口、设备拒绝、未连接等）。排查问题时展开即可。

## 常见问题

**不连接设备能用吗？**

可以。建模、换算、步进、曲线、阻值反解全部离线可用；只有"下发"需要连接设备。
未连接时点 **计算** / 步进只做本地计算，大字温度保持绿色。

**为什么"计算"之后设备没有变化？**

先看大字温度的颜色：**绿色表示只算没发**。检查 **自动设置** 是否勾选（未勾选时需手动点
**应用**），再展开 AT 日志看是否被拒绝过。

**提示"超出设备量程"或"超出限值窗口"？**

换算结果超出了设备能输出的范围（5 Ω ~ 4 MΩ），或超出了你设置的限值窗口。请调整温度范围、
检查模型参数，或修改限值窗口。

**提示"超出标定数据范围"？**

CSV 采用了"原始数据插值"，只能在数据覆盖的温度范围内换算。需要更大范围时改用
**转换为 SH 拟合**（外推结果仅供参考）。

**PV 与目标阻值不一致？**

设备能输出的阻值只能取到离散值，与你请求的值存在固有偏差。**TP** 一栏给出了折算到温度上的
偏差量；低阻端因绝对误差占比大，偏差会更明显。

**B 值法与 Steinhart-Hart 该选哪个？**

两者可以互相校验：先用数据手册的 R25/B 建一个模型，有标定数据后再用 SH 拟合对比残差。
通常的取舍是——只在标定区间内使用、精度要求不高时用 B 值法；需要覆盖较宽温区或更高精度时用
SH（或 CSV 拟合）。

**切换语言/主题后设置会丢失吗？**

不会。主题、语言与"自动设置"开关都保存在浏览器本地（与其它网页工具共用主题/语言设置）。

## 限制

- 仅支持 **AT 模式**；SCPI 模式请使用 SCPI 上位机。
- 页面显示的温度是**模拟值**，不是设备测得的温度；设备自身的内部温度见顶部信息条。
- 设定值与开路/短路状态**不保存**：设备重新上电后输出是断开的、设定值回到默认值，重连后需重新
  下发（勾选自动设置时页面会自动补发一次）。
- **设备限值窗口会保存在设备里**，断电后保持；本页只做设置，不会自动恢复默认值。
- 模型参数（R25/B、A/B/C、标定点、CSV 数据）**只保存在当前页面**，刷新页面即恢复默认值；
  需要长期使用请把参数记录在文件里。
- 设备信息在连接时读取；内部温度会持续刷新；其它设置在你操作后同步。
- 接线与接触电阻不在换算范围内；低阻端（< 100 Ω）使用时请注意引线电阻的影响。
