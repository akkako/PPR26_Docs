# 参考文档索引

## 脚本使用参考

PPR26 提供用户校准和测试 Python 脚本，用户可以自行校准和测试设备。

!!! failure "警告"
    用户自行校准后会丢失出厂校准的数据，请自行确保校准精度。

## 编程参考

PPR26 支持 AT 命令（USB CDC 驱动）和 SCPI 命令（USB TMC 驱动）两种通信模式.

切换模式请参考[此文档](../quickstart/modeswitch.md)。
