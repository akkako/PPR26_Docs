This section describes unboxing, connection, and common operations for the PPR26. It is recommended to read the following pages in order:

| Page | Content |
| ---- | ---- |
| [Unboxing and Connection](getting-started.md) | Packing list, connecting to a PC, panel and interface descriptions |
| [Communication Mode Switching](modeswitch.md) | Switch between AT (USB CDC) and SCPI (USB TMC) |
