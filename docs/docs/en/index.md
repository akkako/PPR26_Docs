# PPR26 Programmable Resistor

PPR26 is a precision programmable resistance box that supports two control methods: **USB-CDC (AT commands)** and **USB-TMC (SCPI commands)**. You can use a host tool to set the output resistance, limits, and output state, and user calibration is supported.
