# Scripts

PPR26 provides Python-based **user calibration**, **test** and **accuracy test** scripts, so that users can calibrate and verify the device themselves.

| Script | Description |
| ---- | ---- |
| [Calibration Script](calibration.md) | User calibration procedure and usage |
| [Test Script](test.md) | Device test procedure and usage (functional self-test) |
| [Accuracy Test](accuracy.md) | Measuring and judging setpoint accuracy (setpoint vs measured) |

!!! warning "Caution"
    Improper calibration reduces output accuracy and reliability; perform it only when a reference standard is available.
