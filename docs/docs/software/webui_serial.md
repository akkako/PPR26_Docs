# 串口上位机（网页版）

网页版串口上位机通过浏览器直接与 PPR26 通信，**无需安装任何软件**，可用于快速设置输出阻值、配置阻值限制与步进、切换开路/短路状态，并查看设备信息。

网址：<https://akkako.github.io/PPR26_Docs/serial/>

!!! note "使用条件"
    - 浏览器：**Chrome / Edge 109 及以上**（需支持 WebSerial）。
    - 设备须工作在 **AT 模式**（USB CDC 虚拟串口），切换方法见[通信模式切换](../quickstart/modeswitch.md)。

## 使用前准备

1. 让设备工作在 AT 模式：设备通过 USB CDC 枚举为串口设备，操作系统通常内置驱动，无需手动安装。
2. 关闭其它可能占用该串口的程序（其它串口工具、Python 脚本、另一个浏览器标签页等）。
3. 用 Chrome 或 Edge 打开 <https://akkako.github.io/PPR26_Docs/serial/>。

## 连接设备

1. 点击 **连接设备**。
2. 在弹出的设备列表中选择 PPR26（设备的 VID:PID 为 `0xFFFE:0xFFFE`）。
3. 连接成功后状态显示 **已连接**，页面自动读取并显示设备信息与当前阻值状态。

!!! tip "看不到设备？"
    - 确认设备处于 **AT 模式**：SCPI 模式（USB TMC）与 DFU 模式的设备**不会**出现在串口列表中。
    - 确认设备已通过 USB 连接到电脑，且其它程序没有占用该串口。
    - 请使用 `https://` 或本机的 `http://localhost` 打开页面，其它地址（例如局域网 IP 的 `http://`）下浏览器会禁用 WebSerial。

点击页头的 **←** 可返回[工具中心](https://akkako.github.io/PPR26_Docs/)；右上角的两个按钮分别用于**切换亮/暗主题**与**中英文界面**，设置会保存在浏览器本地。

## 界面说明

| 区域 | 内容 |
| ---- | ---- |
| **连接** | 连接 / 断开 / 刷新按钮与连接状态 |
| **阻值控制** | 当前**设定阻值**与**实际估测阻值**、设定阻值输入、步进值输入与单步按钮 |
| **阻值限制** | 限值使能开关、最小阻值与最大阻值 |
| **输出状态** | 正常 / 开路 / 短路三态切换 |
| **设备信息** | 型号、序列号、固件版本、硬件版本、生产日期、补偿模式、应用校准数据集、通信协议 |
| **日志** | 上位机与设备之间的收发记录，便于排查问题 |

!!! note "数据读取时机"
    设备配置（输出状态、设定阻值、步进、最小/最大限制等）只在**连接成功时读取一次**；之后每次操作**只发送该操作对应的命令**。唯一例外是**实际估测阻值**：它无法在本地推算，因此每次改变输出（设置阻值、单步、开路/短路/恢复正常）后会额外回读一次。若设备状态被其它方式改变，点击 **刷新** 可重新读取全部信息。

## 功能操作

### 设置输出阻值

1. 在 **阻值控制 → 设定阻值** 输入框中输入数值，并从右侧下拉框选择单位（**Ω / kΩ / MΩ**），支持小数（精度 1 mΩ）。
2. 点击 **设置**，设备随即切换到该阻值，上方显示区同步更新。

可设置的阻值范围为 **5 Ω ~ 4 MΩ**；若启用了阻值限制，则还须落在设定的最小/最大阻值之间，否则操作会被拒绝并提示。

### 步进加减

1. 在 **步进值** 输入框设置步长（单位同样可选 Ω / kΩ / MΩ），点击 **设置** 保存到设备。
2. 点击 **− 单步** / **+ 单步**，设定阻值按步长减少或增加一次；结果会被限制在允许范围内（超出时取边界值）。
3. 步进值为 0 时两个按钮不可用。

### 设置阻值限制

1. 勾选 **启用限值** 后，设定阻值必须落在最小与最大阻值之间。
2. 在 **最小阻值** / **最大阻值** 输入框填写数值与单位，分别点击 **设置** 写入设备。最小阻值不得大于最大阻值。

### 开路 / 短路

在 **输出状态** 区域点击对应按钮：

- **开路**：输出呈高阻（实际估测值显示为"开路"）。
- **短路**：输出直接短路。
- **正常**：退出开路/短路，恢复到当前的**设定阻值**。

进入开路或短路**不会改变**设定阻值；直接设置一个新的阻值也会自动回到正常状态。

## 设备信息说明

| 字段 | 说明 |
| ---- | ---- |
| 型号 | 设备型号，如 `PPR26` |
| 序列号 | 24 位十六进制设备序列号 |
| 固件版本 / 硬件版本 | 当前应用固件版本与硬件版本 |
| 生产日期 | 格式 `YY-WW`（年前两位-周数） |
| 补偿模式 | 输出阻值的拟合方式：`不补偿 (UNCAL)` / `线性 (LINEAR)` / `多档位最佳 (PRECISE)` |
| 应用校准数据集 | 当前生效的校准数据：`用户校准 (USER)` 或 `出厂校准 (FACTORY)`（在网页上仅显示，不可更改） |
| 通信协议 | 当前通信协议，正常应为 `AT` |

## 常见问题

**点击"连接设备"没有任何反应或提示不支持？**

请使用 Chrome / Edge 109+，并确认打开的是 `https://` 地址或本机 `http://localhost`。其它浏览器（如 Safari、Firefox）不提供 WebSerial。

**设备列表里没有 PPR26？**

1. 确认设备工作在 AT 模式（SCPI / DFU 模式不会出现在串口列表中）。
2. 关闭其它占用串口的程序后重新点击"连接设备"。
3. 重新插拔 USB 线缆后再试。

**提示"打开串口失败"或操作超时？**

通常是串口被其它程序或其它浏览器标签页占用。关闭这些程序/标签页，刷新页面后重新连接。

**设置阻值提示失败？**

说明输入值超出了允许范围（5 Ω ~ 4 MΩ），或超出了当前启用的最小/最大限制。请检查输入与限制设置。

**拔掉 USB 线会怎样？**

页面会自动回到"未连接"状态并提示设备已断开；重新插上后再次点击"连接设备"即可。

## 限制

- 仅支持 **AT 模式**；SCPI 模式下请使用 SCPI 上位机。
- 仅提供基础的阻值控制功能，**不支持**校准操作（校准请使用专用上位机）。
- 界面在**连接时读取一次**设备配置，操作时只发送对应命令（不做周期轮询）；需要重新读取时点击 **刷新**。
- 改变输出（设置阻值、单步、开路/短路/恢复正常）后会回读一次"实际估测"阻值；其余配置项不自动回读，需要时点击 **刷新**。
