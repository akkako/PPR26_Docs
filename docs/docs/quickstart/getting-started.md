# 快速入门

## 发货清单

购买 PPR26 程控电阻套件，其包装内应该具有如下物品：

| 物品                   | 数量 | 说明                                             |
| ---------------------- | ---- | ------------------------------------------------ |
| USB-A 转 USB-B 线缆    | 1    | 用于供电和数据通信                               |
| PPR26 程控电阻         | 1    | 仪器本体                                         |
| 两线香蕉头转接线夹线缆 | 1    | 用于连接输出                                     |
| 使用说明书             | 1    | 简单使用说明，详细说明扫描二维码导航至本线上文档 |
| 精度测试报告           | 1    | 出厂校准后的精度测试报告                         |

## 连接 PC

将 PPR26 通过附带的 USB-A 转 USB-B 数据线接入 PC，PPR26 仅需要最大 2.5W 的功率，因此可以完全由 PC 进行供电。

在连接供电后，前面板的绿色电源指示灯将点亮。

!!! warning "注意事项"
    不要使用 USB 延长线，PPR26 会抽取最大 500mA 的电流，线阻过大会导致电源压降过大，设备可能不能正常工作。

## 设备前面板

设备前面板分别为两个 Sense 端子和两个 Output 端子，不区分极性，连接器的类型为 4mm 香蕉头。

## 设备后面板

设备后面板从左到右分别为 USB-B 供电与数据接口，电源指示灯，DFU 模式按键。
