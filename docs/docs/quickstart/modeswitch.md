# 通信模式切换

PPR26 具有两种通信模式，分别用于不同的上位机与使用场景：

| 模式     | 协议栈                    | PC 端枚举方式            | 常用上位机                          |
| -------- | ------------------------- | ------------------------ | ----------------------------------- |
| **AT**   | 自定义 AT 命令（USB CDC） | USB 串口（虚拟串口）     | 串口工具、`pyserial`、[网页串口上位机](../software/webui_serial.md) |
| **SCPI** | SCPI 命令（USB TMC）      | USB TMC 设备             | NI‑VISA / `pyvisa`、符合 SCPI 的仪器软件 |

- 出厂默认工作在 **AT 模式**。
- AT 模式（USB CDC）通常免驱；SCPI 模式（USB TMC）需要安装驱动（推荐 NI‑VISA）。

## 如何判断当前模式

通过 PC 端枚举到的设备类型即可区分：

| 模式     | 枚举结果                          | 标识（VID:PID） |
| -------- | --------------------------------- | --------------- |
| AT       | USB 串行设备（COMx）              | `FFFE:FFFE`     |
| SCPI     | USB Test and Measurement Device   | `FFFE:FFFF`     |
| DFU 引导 | `PPR26 WinUSB DFU`（仅固件升级）  | `FFFE:FFFD`     |

## 切换方法

### 方法一：软件命令（运行时切换，推荐）

在**当前模式**下发送对应的切换命令即可，无需断电：

=== "AT → SCPI"

    ```text
    AT+SYS.PROT=1
    ```

=== "SCPI → AT"

    ```text
    SYST:PROT AT
    ```

- 切换为**运行时切换**：设备断开并重新连接 USB（D+），随后按新协议重新枚举。
- 切换命令执行后当前连接会中断，属于正常现象；请等待设备重新枚举，再用对应协议的上位机重新连接。
- 切换结果会被保存，**断电重启后保持上次选择的模式**。

!!! tip "提示"
    也可以在对应的 Python 脚本中切换：AT 使用 `pyserial` 发送 `AT+SYS.PROT=1`；SCPI 使用 `pyvisa` 发送 `SYST:PROT AT`。

### 方法二：DFU 按键

设备上的 **DFU 按键**在两种状态下作用不同：

| 使用方式                     | 作用                                             |
| ---------------------------- | ------------------------------------------------ |
| **运行中长按约 3 秒**        | 在 AT 与 SCPI 之间切换（等同于方法一的软件命令） |
| **上电时按住按键再接入电源** | 进入 **DFU 引导模式**，用于固件升级               |

!!! warning "注意"
    - 运行中长按切换协议为运行时切换，USB 会断开重连，不会进入 DFU。
    - 只有在**上电/复位时按住**按键才会进入 DFU 模式；DFU 模式仅用于固件升级，不能用于通信。升级流程见[固件升级指南](./fwupgrade.md)。

## 切换后的连接

切换完成后按新协议重新连接：

- **AT 模式**：使用串口工具或 `pyserial`，串口参数 `115200 / 8 / None / 1`，命令以换行结束。参见 [AT 命令参考](../reference/at.md) 与 [AT Python 编程示例](../reference/python_at.md)。
- **SCPI 模式**：使用 NI‑VISA / `pyvisa`，资源形如 `USB0::0xFFFE::0xFFFF::<序列号>::0::INSTR`，命令以换行 `<LF>` 结束。参见 [SCPI 命令参考](../reference/scpi.md) 与 [SCPI Python 编程示例](../reference/python_scpi.md)。

## 常见问题

**切换后找不到设备？**

设备在切换过程中会断开并重新枚举，请稍候并刷新上位机的设备列表。若仍找不到：

- 确认设备已按新协议枚举（AT 为 USB 串口，SCPI 为 USB TMC 设备）。
- SCPI 模式需安装驱动（推荐 NI‑VISA），否则设备可能因缺少驱动而无法打开。
- 关闭可能占用设备的其它程序，或重新插拔 USB。

**长按按键没有进入 DFU？**

运行中长按是**切换协议**；进入 DFU 需要在**上电时按住**按键（先断开电源，按住按键后再接入电源，之后松开）。参见[固件升级指南](./fwupgrade.md)。

**网页串口上位机看不到设备？**

网页串口上位机仅支持 **AT 模式**；若设备处于 SCPI 模式，请先切换回 AT 模式。
